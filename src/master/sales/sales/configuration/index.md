# Configuration

Configuration holds the one-time setup of the **Sales** module. **Settings** decide which features are available. **Configurations** hold the lists those features use, such as categories, packagings and tags.

> **In simple words:** Settings switch features on. Configurations fill them with data.

## Settings

Open `Sales → Settings` to manage module-wide options.

- [Settings](./settings.md): products, invoice policy, pricing, and quotation and order options.

## Configurations

Open `Sales → Configurations` to manage these lists.

- [Product categories](./product-categories.md): group products in a tree.
- [Product attributes](./product-attributes.md): define options such as size or colour for variants.
- [Packagings](./packagings.md): define pack sizes for a product.
- [Tags](./tags.md): colour labels for sales orders.
- [UOM categories](./uom-categories.md): units of measure and how they convert.

Activity Plans and Activity Types appear in the same menu. They work the same way across Aureus, so they are covered in [Activities](../../../getting-started/activities.md).
