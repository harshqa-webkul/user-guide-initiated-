# Tags

Tags are colour labels for sales orders. They help you filter and spot orders, such as Urgent or Repeat Customer.

> **In simple words:** A tag is a coloured sticker for an order.

## Overview

Go to `Sales → Configurations → Sales Orders → Tag`.

<ImagePopup src="/images1/sales/cfg_tags_list.png" alt="Tags list with the Priority tag, its colour and the New Tag button" />

The list shows **Name**, **Color** and **Created by**. Use the search box to find a tag.

## Create a tag

1. Go to `Sales → Configurations → Sales Orders → Tag`.
2. Click **New Tag**. A window opens.
3. Fill in the fields.

   - **_Name\:_** Required. Enter the tag name.
   - **_Color:_** Pick a colour or enter a hex code, such as #941c79.

   <ImagePopup src="/images1/sales/sales_order_tag_form.png" alt="Create Tag window with name and colour" />

4. Click **Create**. Click **Create & create another** to add more.

## Actions

- **View:** Open the tag.
- **Edit:** Change the name or colour.
- **Delete:** Remove the tag. Select several rows to delete them together.
