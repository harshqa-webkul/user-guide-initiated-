# Get started with Point of Sale

This group takes you from a fresh install to a register that is ready to sell. You learn the menus first. Then you create a register and tune the module settings that apply to all registers.

> **In simple words:** Learn the layout, build your register, then set the shared rules.

## What to do, in order

1. Read [POS overview](pos-overview.md) to learn the admin menus, the terminal pages and the numbers POS creates.
2. Follow [Set up a register](set-up-a-register.md) to create a register and fill each tab of its form.
3. Open [POS settings](pos-settings.md) to choose the default accounts, price lists and stock update timing.
4. Go to [Open a register](../sessions/open-register.md) and start your first session.

## Pages in this group

| Page | Use it to |
| --- | --- |
| [POS overview](pos-overview.md) | Find your way around the admin app and the terminal |
| [Set up a register](set-up-a-register.md) | Create a register and set every option |
| [POS settings](pos-settings.md) | Set accounts, price lists and stock updates for all registers |

::: info
A register is also called a Point of Sale. In the admin it is listed under `Point of Sale → Configurations → Point of Sale`.
:::
