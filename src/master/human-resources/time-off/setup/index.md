# Set up Time Off

Setup tells Aureus what kinds of leave exist and which dates are special. You do it once, then adjust it when your policy changes. Three pages hold the setup, all under **Configuration**.

> **In simple words:** Setup is where you name the kinds of leave and list the days off for everyone.

## The three setup pages

| Page | Menu path | What it is |
| --- | --- | --- |
| [Leave types](time-off-types.md) | `Time Off → Configuration → Leave Types` | The kinds of leave people can request, and the rules of each |
| [Public holidays](public-holidays.md) | `Time Off → Configuration → Public Holidays` | Days off for the whole company, such as New Year's Day |
| [Mandatory days](mandatory-days.md) | `Time Off → Configuration → Mandatory Holidays` | Days when the company expects everyone to be at work |

## How they relate

A leave type is a rule book for requests. Choose it on every request and every allocation. It decides who approves and whether days must be given first.

Public holidays and mandatory days are lists of dates. They are informational. Staff see them in the **Holidays** window on `Time Off → My Time → Dashboard`.

::: info Order
Create leave types first. Allocations and requests need them. Add holidays and mandatory days whenever you like.
:::

## Seeded data

- Seven leave types, such as **Paid Time Off** and **Sick Time Off**.
- Thirteen public holidays for 2025.
- One mandatory day, **Company Anniversary**.

## Typical setup order

1. Review the seven leave types and edit or add yours.
2. Add your public holidays.
3. Add mandatory days if you use them.
4. Give days to people. See [Allocations](../allocations/index.md).
