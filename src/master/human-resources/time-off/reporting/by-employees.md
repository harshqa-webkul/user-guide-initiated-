# By Employees report

The By Employees report lists time off requests grouped by employee. Use it to see who is away, for how long, and which requests still wait for a decision. It helps managers compare the leave taken across the team.

> **In simple words:** One list of requests, with each employee's requests gathered under their name.

Open `Time Off → Reporting → By Employees`.

::: info Before you start
The report shows [time off requests](../requests/index.md). Create some requests first.
:::

## Overview

The page is titled **By Employees**. It groups rows by **Employee** by default. Each group title looks like `Employee: Nina Patel`. Click a group to open or close it.

- **_Employee:_** The person who asked for leave.
- **_Time Off Type:_** The kind of leave.
- **_Description:_** The note typed on the request.
- **_Date From:_** The first day of leave.
- **_Date To:_** The last day of leave.
- **_Duration:_** The length, for example `5 day(s)`.
- **_Status:_** **To Approve**, **Approved** or **Refused**.

## Tabs, grouping and search

1. Click a tab to filter the list. The tabs are **Default**, **Waiting For Me**, **Second Approval** and **Approved**. The report opens on **Waiting For Me**.
2. Click **Default** to see all requests.
3. Open **Group by** to change the grouping. Choose **Employee**, **Time Off Type**, **Status**, **Start Date** or **End Date**. Use the **Group direction** option to switch between **Ascending** and **Descending**.
4. Type in the search box to find an employee or a request.

<ImagePopup src="/images1/time-off/report_by_employees_groupby.png" alt="Group by menu on the By Employees report with Employee, Time Off Type, Status, Start Date and End Date and the Group direction option" />

Use a row to **View** or **Edit** the request. Approve and refuse requests in [Manage requests](../requests/manage-requests.md).

::: tip
Group by **Time Off Type** to see how much of each leave type your team uses.
:::
