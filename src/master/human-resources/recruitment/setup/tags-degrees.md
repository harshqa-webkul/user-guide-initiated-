# Tags and degrees

Tags and degrees add detail to your applicants. A tag is a coloured label, such as Warehouse Management, that helps you group and find people. A degree records the education level of a person. Both come from lists that you maintain once.

> **In simple words:** Tags are coloured labels for applicants. Degrees are education levels you pick from a list.

Open `Recruitments → Configuration → Tags` or `Recruitments → Configuration → Degrees`.

::: info Prerequisite
None. Both lists come with sample data.
:::

## Tags

### Overview

The list shows the columns **Name** and **Color**. The color appears as a small swatch. Sample tags include **Sales**, **Manager**, **IT**, **HR**, **Warehouse Management** and **Project Management**.

<ImagePopup src="/images1/recruitment/set_tags_list.png" alt="Tags list with the Name column and Color swatches" />

### Create a tag

1. Open `Recruitments → Configuration → Tags`.
2. Click **New Tag**. A **Create Tags** window opens.
3. Type **Warehouse Supervisor** in **Name**.
4. Pick a color in **Color**.
5. Click **Create**.

<ImagePopup src="/images1/recruitment/set_tag_create.png" alt="Create Tags window with the name Warehouse Supervisor and a color chosen" />

- **_Name:_** (required) the label text.
- **_Color:_** (required) pick a color with the picker. It has no default.

### Where tags are used

You choose tags in the **Tags** field of the applicant form. A candidate has tags too. When an applicant has none, it shows the tags of its candidate.

## Degrees

### Overview

The list has one column, **Name**. The sample data holds 24 degrees, for example **Bachelor**, **Master**, **Doctoral Degree** and **Chartered Accountant (CA)**.

<ImagePopup src="/images1/recruitment/set_degrees_list.png" alt="Degrees list with the Name column" />

### Create a degree

1. Open `Recruitments → Configuration → Degrees`.
2. Click **New Degrees**. A **Create Degrees** window opens.
3. Type a name, for example **Diploma in Logistics**.
4. Click **Create**.

<ImagePopup src="/images1/recruitment/set_degree_create.png" alt="Create Degrees window with the name Diploma in Logistics" />

- **_Name:_** (required) the degree as people will read it.

### Where degrees are used

The **Degree** field sits in the **Education & Availability** section of the applicant form. It is saved on the candidate too.
