# Recruitment setup

Setup holds the lists that feed the applicant form and the hiring flow. You set them once and then pick from them while you work. Good setup saves typing and keeps your reports consistent.

> **In simple words:** Setup is where you define stages, reasons, tags and other choices that applicants use.

Open `Recruitments → Configuration`. The menu on the left lists every setup page.

## Pages written for Recruitment

| Page | What it holds | Used on |
| --- | --- | --- |
| [Stages](stages.md) | The steps an applicant passes through, with state labels and a hired flag | The stage bar of an applicant |
| [Refuse reasons](refuse-reasons.md) | Why an application is refused, with the email template | The **Refuse** window |
| [Tags and degrees](tags-degrees.md) | Coloured labels and education levels | The applicant and candidate forms |
| [Sources and mediums](sources-and-mediums.md) | Where the applicant came from | The **Source & Medium** section |

## What to set up first

1. Check the [stages](stages.md). The sample stages work for most teams.
2. Check the [refuse reasons](refuse-reasons.md).
3. Add the [tags and degrees](tags-degrees.md) you use.
4. Add the [sources and mediums](sources-and-mediums.md) you track.

::: tip
Recruitment has no separate settings page. Everything is managed from this menu.
:::
