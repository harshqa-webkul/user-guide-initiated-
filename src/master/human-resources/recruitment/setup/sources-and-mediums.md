# Sources and mediums

Sources and mediums tell you where an applicant came from. A source is the place, such as LinkedIn or Referral. A medium is the channel used to reach you, such as Email or Phone. Tracking both shows which hiring channels work best.

> **In simple words:** Source is where the applicant found you. Medium is how they reached you.

Open `Recruitments → Configuration → Sources` or `Recruitments → Configuration → Mediums`.

::: info Prerequisite
None. Both lists come with sample data.
:::

## Sources

The list has one column, **Name**. Sample sources are **Search engine**, **Lead Recall**, **Newsletter**, **Facebook**, **X**, **LinkedIn**, **Monster**, **Glassdoor**, **Craigslist** and **Referral**.

<ImagePopup src="/images1/recruitment/set_sources_list.png" alt="Sources list with sample sources such as LinkedIn and Referral" />

### Create a source

1. Open `Recruitments → Configuration → Sources`.
2. Click **New Source**. A **Create Sources** window opens.
3. Type **Job Fair** in **Name**.
4. Click **Create**.

<ImagePopup src="/images1/recruitment/set_source_create.png" alt="Create Sources window with the name Job Fair" />

- **_Name:_** (required) the source label.

## Mediums

Sample mediums are **Phone**, **Direct**, **Email**, **Banner**, **X**, **Facebook**, **LinkedIn**, **Television**, **Google** and **Referral**.

<ImagePopup src="/images1/recruitment/set_mediums_list.png" alt="Mediums list with sample mediums such as Email and Phone" />

### Create a medium

1. Open `Recruitments → Configuration → Mediums`.
2. Click **New Medium**. A **Create Mediums** window opens.
3. Type **Walk-in** in **Name**.
4. Click **Create**.

<ImagePopup src="/images1/recruitment/set_medium_create.png" alt="Create Mediums window with the name Walk-in" />

- **_Name:_** (required) the medium label.

## Where they are used

The applicant form has a **Source & Medium** section with a **Source** field and a **Medium** field. Pick one value from each. For Rahul Verma, you could choose **Referral** as the source and **Email** as the medium.

::: info
Sources and mediums are shared records. Other apps that track campaigns read the same lists.
:::
