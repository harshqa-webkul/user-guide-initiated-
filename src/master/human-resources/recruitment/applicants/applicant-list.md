# Applicant list

The applicant list shows every application in one table. You use it to find people, see who is in which stage, and open an applicant. Tabs, grouping, filters and columns let you answer questions such as "Who is in the second interview?".

> **In simple words:** One table of all applications, grouped by stage. Use tabs and filters to narrow it down.

Open `Recruitments → Applications → Applicants`.

## Overview

The page title is **Applicants**. **New Applicant** at the top right creates an application. See [Add an applicant](add-applicant.md). Under the title you see the tabs, then the search box, the filter icon, the column icon and the **Group by** selector.

<ImagePopup src="/images1/recruitment/applicants_list_default.png" alt="Applicants list with the preset tabs, Group by Stage and applicants grouped under stage headers" />

Click a row to open the applicant. Each group header reads **Stage: New**, **Stage: First Interview** and so on. Click a header to collapse it.

### Tabs

The tabs are saved views. The row of tabs shows five of them:

- **Default:** all applicants, grouped by **Stage**.
- **My Applicants:** applicants where you are the recruiter.
- **Un Assigned:** applicants without a recruiter.
- **In Progress:** applicants still in the process.
- **Archived:** inactive applicants, such as refused ones.

<ImagePopup src="/images1/recruitment/applicants_list_tabs.png" alt="Row of preset tabs Default, My Applicants, Un Assigned, In Progress and Archived" />

Click the three dots next to the tabs to see more views. Each has **Apply View** and **Add to Favorites**. Favorites show as tabs.

<ImagePopup src="/images1/recruitment/applicants_list_presets_menu.png" alt="Menu of saved views with Hired, Refused, Blocked, Directly Available, Created Recently and Stage Updated Recently" />

- **Hired:** applicants who reached a hired stage.
- **Refused:** applicants with the refused status.
- **Blocked:** applicants whose state is blocked.
- **Directly Available**, **Created Recently** and **Stage Updated Recently**: extra views you can apply.

::: info
In the sample data, **My Applicants**, **Refused**, **Directly Available**, **Created Recently** and **Stage Updated Recently** show no rows. A view shows rows only when applicants match it. For example, **My Applicants** lists applicants whose recruiter is you.
:::

Use **Add New** in the same menu to save your own view. **Reset** returns to the standard views.

## Group the list

**Group by** starts on **Stage**. Choose another value:

- **Job Position**
- **Candidate Name**
- **Responsible**
- **Creation Date**
- **Hired Date**
- **Last Stage**
- **Refuse Reason**

Choose `-` for no grouping. Set the direction to **Ascending** or **Descending**.

<ImagePopup src="/images1/recruitment/applicants_list_group_by.png" alt="Group by selector open with the grouping options listed" />

## Columns

Three columns show at first: **Partner Name**, **Applied On** and **Job Position**. Click the column icon to add more:

**Stage**, **Candidate Name**, **Application Status**, **Refuse Reason**, **Evaluation**, **Tags**, **Email**, **Recruiter**, **Interviewer**, **Phone**, **Medium**, **Source**, **Expected Salary** and **Availability Date**.

<ImagePopup src="/images1/recruitment/applicants_list_columns.png" alt="Column toggle panel with extra columns such as Stage, Recruiter and Expected Salary switched on" />

## Search and filters

Type in the search box to find an applicant. Click the funnel icon to build a filter. You can filter by:

**Source**, **Medium**, **Candidate**, **Last Stage Updated**, **Stage**, **Job Position**, **Priority**, **Applied On** and **Hired Date**. Salary and **Applicant Notes** are also available.

<ImagePopup src="/images1/recruitment/applicants_list_filter.png" alt="Filter panel open with a Job Position condition set to Warehouse Supervisor" />

See [Search, filter and group](../../../getting-started/search-filter-group.md) for how filters work.

## Row actions

The kebab menu on a row has **View**, **Edit** and **Delete**. The clock icon opens the activity action. See [Schedule an activity](../../../getting-started/chatter/actions/activity.md). Select rows to delete several at once.

<ImagePopup src="/images1/recruitment/applicants_list_row_actions.png" alt="Row menu with View, Edit and Delete beside an applicant" />

::: tip
Blocked applicants do not show in the normal tabs. Apply the **Blocked** view to find them.
:::
