# Candidates

A candidate is a person in your talent pool. It holds their name, contact details, degree, tags and skills once. Each time the person applies for a job, Aureus creates an applicant linked to the candidate. Because of this, you never retype details when someone applies twice.

> **In simple words:** The candidate is the person. Create it once and reuse it for every application.

Open `Recruitments → Applications → Candidates`.

## Overview

The page lists candidates as cards. Use **Sort by** to order them by **Full Name**. Group them by **Manager**. Each card has **View**, **Edit** and **Delete**.

## Create a candidate

You can also create a candidate while [adding an applicant](add-applicant.md).

1. Click **New Candidate**. The page is titled **Create Candidate**.

### Basic Information

2. Fill in the person's details.

- **_Full Name:_** Required. Example: `Rahul Verma`.
- **_Email Address:_** The email used for messages. Example: `rahul.verma@example.com`.
- **_Phone Number:_** The contact number.
- **_LinkedIn Profile:_** The link to the person's profile.

<ImagePopup src="/images1/recruitment/candidate_create_basic.png" alt="Create Candidate form with the Basic Information section filled for Rahul Verma" />

### Additional Details

3. Add the rest if you know it.

- **_Degree:_** The highest degree. Create options in [Tags and degrees](../setup/tags-degrees.md).
- **_Tags:_** Labels that describe the person.
- **_Manager:_** The user who looks after this candidate.
- **_Availability Date:_** When the person can start.
- **_Status:_** A toggle for an active candidate.
- **_Evaluation:_** A star rating.

<ImagePopup src="/images1/recruitment/candidate_create_additional.png" alt="Additional Details section with degree, tags, manager, availability date, status and evaluation filled in" />

4. Click **Create**, or **Create & create another** to add more.

## Skills

Open a candidate and use the **Skills** table, or the **Manage Skills** tab. Click **Add Skill** to record a skill. Each row shows **Skill Type**, **Skill**, **Skill Level** and **Level Percent**. Use the row actions to view, edit or delete a skill. Skill types are set up in the employee settings.

<ImagePopup src="/images1/recruitment/candidate_skills_table.png" alt="Skills table of a candidate with Skill Type, Skill, Skill Level and Level Percent columns and the Add Skill button" />

## Actions

- **Create employee:** on the candidate page, turns the person into an employee.
- **Delete:** removes the candidate.
