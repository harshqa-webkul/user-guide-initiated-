# Get started with Employees

This group gets you from an empty company structure to a complete employee profile. You learn the order of work first, then try it with a real example. After this group, the other pages go deeper into each screen.

> **In simple words:** Build the places first, then add the person, then fill in what they do.

## What you will do

1. Create a department.
2. Create a job position inside that department.
3. Add an employee who uses both.
4. Add private details, a skill and two resume lines.
5. Find the employee on the list.
