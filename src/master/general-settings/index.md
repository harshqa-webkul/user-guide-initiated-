# General settings

The **Settings** app is where an administrator controls how Aureus ERP works for everyone. It holds your users, roles, companies and teams. It also holds the options that apply across all modules, such as the base currency and the look of the application.

> **In simple words:** Settings is the control room for people, companies and system-wide options.

## Top tabs

The Settings app has these tabs at the top of the screen:

- **Roles:** Define what each group of users may see and do. See [Roles](./users/roles.md).
- **Companies:** Add and edit the companies you work for. See [Companies](./companies/companies.md).
- **Teams:** Group users into teams. See [Teams](./users/teams.md).
- **Users:** Create users and invite new ones. See [Users](./users/users.md).
- **Custom Fields:** Add your own fields to records. See [Custom fields](./customization/custom-fields.md).
- **Sequences:** Control how document numbers are built. See [Sequences](./customization/sequences.md).
- **Settings:** Open the option pages described below.

## The General group

Click the **Settings** tab to open a menu on the left. The **General** group has these pages:

- **Manage Activities:** Create and edit activity types. See [Activities](../getting-started/activities.md).
- **Manage Currency:** Choose the base currency. See [Manage currency](./companies/currency.md).
- **Manage Users:** Set invitation, password reset and default values for new users. See [Manage users](./users/manage-users.md).
- **Branding:** Change logos, favicon and colors. See [Branding](./customization/branding.md).

Each installed module can add its own group to this menu.

<ImagePopup src="/images1/general-settings/settings_left_menu.png" alt="Settings tab with the left menu showing the General group" />

::: info
You see only the pages your role allows. If a page is missing, ask an administrator to check your role.
:::
