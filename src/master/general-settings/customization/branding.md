# Branding

The **Branding** page lets you replace the default logos, favicon and theme colors. The changes apply across the admin and customer panels. Use it to make the application match your company identity.

> **In simple words:** Upload your logo and pick your colors, and the application looks like yours.

## Open the page

1. Go to `Settings → Settings`.
2. In the left menu, under **General**, click **Branding**.

<ImagePopup src="/images1/general-settings/branding_page.png" alt="Branding page with the Logo & Favicon and Colors sections" />

## Change logos and favicon

The **Logo & Favicon** section has these fields. Leave a field empty to keep the default.

- **_Light Logo:_** Shown on light backgrounds. It replaces the default logo.
- **_Dark Logo:_** Shown when dark mode is on.
- **_Favicon:_** The icon in the browser tab.
- **_Logo Height:_** A size such as `40px`. A larger number makes the logo taller.

Each upload accepts image files only.

<ImagePopup src="/images1/general-settings/branding_logos.png" alt="Logo & Favicon section with the four fields" />

## Change colors

The **Colors** section has six color pickers. Leave one empty to keep the default.

- **_Primary:_** The main color. Default is a blue.
- **_Gray:_** Neutral tones. Default is a zinc gray.
- **_Danger:_** Errors and delete actions. Default is red.
- **_Info:_** Information messages. Default is blue.
- **_Success:_** Success messages. Default is green.
- **_Warning:_** Warnings. Default is amber.

Enter the color as a hex code, for example `#2563eb`, or use the picker.

<ImagePopup src="/images1/general-settings/branding_colors.png" alt="Colors section with the six color pickers and the Reset to default link" />

To go back to the default colors, click **Reset to default** in the section header. Confirm the prompt. Then click **Save changes**.

::: info
**Reset to default** fills in the default colors. They are not stored until you click **Save changes**. It does not reset the logos.
:::

## Save

Click **Save changes** to apply your branding.
