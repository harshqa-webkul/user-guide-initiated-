# Get started with Inventory

This group gets you from an empty module to your first stock movement. You learn where things are on screen, which settings to turn on, and how one product travels from purchase to sale.

> **In simple words:** Look around, switch on what you need, then follow the tutorial once.

## The path

```text
Overview  →  Settings  →  First steps
(see it)     (turn on)    (do it)
```

1. Read [Inventory overview](inventory-overview.md). It explains the dashboard cards and every menu in the top bar.
2. Read [Inventory settings](inventory-settings.md). It explains the five settings pages and what each toggle reveals.
3. Follow [First steps](first-steps.md). You receive stock from a purchase order, see it in the stock report, then deliver it from a sales order.

## Pages in this group

| Page | Use it to |
| --- | --- |
| [Inventory overview](inventory-overview.md) | Understand the dashboard cards and the menu tour |
| [Inventory settings](inventory-settings.md) | Turn on Locations, Lots, Packages and more |
| [First steps](first-steps.md) | Run a full receive and deliver cycle |

::: tip
Settings change what you see. If a menu in this guide is missing from your screen, check the settings page first.
:::
