# Get started with Maintenance

This group helps you run your first maintenance job from start to finish. You do not need to know maintenance software. You only need the Maintenance app open in your browser.

> **In simple words:** Do the tutorial once. After that, the rest of the guide is a reference you can open when you need it.

## What you need first

Before you create anything, three things must exist. Aureus ships with some of them.

- **Stages.** Four stages come ready: **New Request**, **In Progress**, **Repaired** and **Scrap**. See [Stages](../setup/stages.md).
- **A team.** The team **Internal Maintenance** comes ready. You can add your own. See [Maintenance teams](../setup/maintenance-teams.md).
- **A category.** Equipment belongs to a category, so make one before you add equipment. See [Equipment categories](../setup/equipment-categories.md).

## The tutorial in one view

The tutorial uses one machine, a **Hydraulic Press 200T**, from beginning to end.

| Part | What you do |
| --- | --- |
| Setup | Check stages and team, create a category and a team |
| Equipment | Add the press with its vendor, serial number, category and warranty |
| Corrective job | Report an oil leak, assign it, schedule it for 14 October 2026, move it to **Repaired** |
| Calendar | See the scheduled job on the calendar |
| Preventive job | Set up a monthly lubrication, first due 20 October 2026, that repeats on its own |
