# Get started with Purchase

This group takes you from an empty Purchase app to your first vendor bill. You choose which features to switch on, then follow one example from a new vendor to a vendor bill. Read the settings page once, then work through the tutorial.

> **In simple words:** Set the rules, then buy something.

```text
Purchase settings  →  First steps (vendor, product, RFQ, receipt, bill)
```

## Pages in this group

| Page | Read it to |
| --- | --- |
| [Purchase settings](purchase-settings.md) | Turn on approval, locking, agreements, variants, units and packagings |
| [First steps](first-steps.md) | Walk one product through the whole buying flow |

## Before you start

1. Create your vendor in Contacts, or follow Step 1 of First steps, which creates it for you. See [Contacts](../../../getting-started/contacts/contacts.md).
2. Install the Inventory app if you want receipts. See [Inventory](../../inventories/index.md).
3. Check that your company currency is set. Orders use it by default.
4. Install the Invoices or Accounting app and set up a purchase journal if you want vendor bills. See [Vendor bills](../orders/vendor-bills.md).

::: tip
Read [Purchase settings](purchase-settings.md) once. Then follow [First steps](first-steps.md).
:::
