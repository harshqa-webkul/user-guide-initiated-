# Get started with Purchase

This group takes you from an empty Purchase app to your first paid order. You choose which features to switch on, then follow one example from a new vendor to a vendor bill. Read the settings page once, then work through the tutorial.

> **In simple words:** Set the rules, then buy something.

```text
Purchase settings  →  First steps (vendor, product, RFQ, receipt, bill)
```

## Pages in this group

| Page | Read it to |
| --- | --- |
| [Purchase settings](purchase-settings.md) | Turn on approval, locking, agreements, variants, units and packagings |
| [First steps](first-steps.md) | Walk one product through the whole buying flow |

## Before you start

1. Create your vendor in Contacts. See [Contacts](../../../getting-started/contacts/contacts.md).
2. Install the Inventory app if you want receipts. See [Inventory](../../inventories/index.md).
3. Check that your company currency is set. Orders use it by default.

::: tip
New to buying? Read [First steps](first-steps.md) first. Come back to settings when you need a feature it switches on.
:::
