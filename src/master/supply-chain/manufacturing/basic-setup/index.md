# Basic setup

Basic setup is what you prepare before the first manufacturing order. You need a product that can be built, a recipe for it and the right warehouse steps. Costs then show up on each order.

> **In simple words:** Product, recipe, warehouse steps. Then you can build.

## Suggested order

1. [Configure a product](configure-product.md) for the finished item and for each component.
2. Write the [bill of materials](bill-of-materials.md).
3. Pick the warehouse steps you want.
4. Create your first order from [First steps](../get-started/first-steps.md).
