# Get started with Manufacturing

This group gets you ready to build your first product. You decide which Manufacturing features to switch on, then follow one full example from recipe to finished goods.

> **In simple words:** Switch on what you need, then build one product from start to end.

## Pages in this group

| Page | Read it to |
| --- | --- |
| [Manufacturing settings](manufacturing-settings.md) | Turn on **Work Orders** and **Work Order Dependencies** |
| [First steps](first-steps.md) | Follow one manufacturing order from Draft to Done |

## Suggested order

1. Read the [Manufacturing overview](../index.md) to see the whole flow.
2. Open [Manufacturing settings](manufacturing-settings.md). A simple build needs no setting. Routing steps need **Work Orders**.
3. Walk through [First steps](first-steps.md) with the Business Laptop example.
4. Go deeper in [Basic setup](../basic-setup/index.md).
