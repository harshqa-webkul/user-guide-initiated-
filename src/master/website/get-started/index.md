# Get started with Website

This group helps you learn the Website app before you build anything. You first see what every menu does and how it changes the public site. Then you follow one tutorial that takes you from empty contact details to a live blog post.

> **In simple words:** Learn the map first, then build your first site.

## Pages in this group

| Page | Use it to |
| --- | --- |
| [Website overview](website-overview.md) | Learn every admin menu, the dashboard filters, stats and widgets, and which option controls which part of the public site |
| [First steps](first-steps.md) | Follow one tutorial: contacts, Home page, new page in the header menu, category, tag, blog post, public check |

## Suggested order

1. Read the [Website overview](website-overview.md) once.
2. Follow [First steps](first-steps.md) on your own system.
3. Open the depth pages when you need more detail.

```text
Overview  →  First steps  →  Pages  →  Blog  →  Customers
```

::: tip
Do the tutorial with sample content first. You can delete or edit the records later.
:::
