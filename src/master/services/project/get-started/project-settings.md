# Project settings

Project settings switch optional features on or off for your whole company. A feature you switch off is hidden from forms and menus. This keeps screens short for teams that do not need milestones or time tracking.

> **In simple words:** Three switches decide which fields and pages you see in Project.

There are two settings pages. Open `Project → Settings → Manage Tasks` and `Project → Settings → Manage Time`. Both have a **Save changes** button. Click it after every change.

::: info Who can see these pages
You need permission to open Settings. Ask an administrator if the menu is missing. See [Manage users](../../../general-settings/users/manage-users.md).
:::

## Manage Tasks

1. Open `Project → Settings → Manage Tasks`.
2. Switch the toggles you need.
3. Click **Save changes**.

<ImagePopup src="/images1/project/st_manage_tasks.png" alt="Manage Tasks settings page with Enable Project Stages and Enable Milestones toggles and the Save changes button" />

- **_Enable Project Stages:_** Shows the stage bar on the project form. Pick a stage such as **In Progress** for each project. The stage list lives in `Project → Configurations → Project Stages`. Off by default.
- **_Enable Milestones:_** Adds the **Allow Milestones** toggle to projects. It also adds the **Milestones** page and the **Milestone** field on tasks. On by default.

The page also shows a **Configure Stages** link next to **Enable Project Stages**.

## Manage Time

1. Open `Project → Settings → Manage Time`.
2. Switch on **Enable Timesheets**.
3. Click **Save changes**.

<ImagePopup src="/images1/project/st_manage_time.png" alt="Manage Time settings page with Enable Timesheets switched on and the Save changes button" />

- **_Enable Timesheets:_** Lets people log hours on tasks. Off by default.

When **Enable Timesheets** is on, these appear:

- **Allow Timesheets** on each project.
- **Allocated Hours** on projects and tasks.
- A **Timesheets** tab on tasks.
- Time columns and filters on the task list.
- The **Timesheets** item in the Project menu.

## Per project switches

The settings above are company wide. Each project then chooses for itself.

- **_Allow Timesheets:_** Shown only when **Enable Timesheets** is on. Without it the project has no **Timesheets** tab on its tasks.
- **_Allow Milestones:_** Shown only when **Enable Milestones** is on. Without it the project has no milestones and its tasks have no **Milestone** field.

You set both on the project form. See [Create a project](../project-management/create-project.md).

::: tip
For the example in this guide, **Enable Timesheets** and **Enable Milestones** are on. **Website Revamp** has both **Allow Timesheets** and **Allow Milestones** on.
:::

## Actions and statuses

- **Save changes:** stores the toggles. Forms show the new fields at once.
- Switching a feature off hides its fields and pages.
