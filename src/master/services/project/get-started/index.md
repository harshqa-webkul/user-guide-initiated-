# Get started with Project

Before you create your first project, decide which features you want. Project has three switches in **Settings**. They add fields and pages to your projects and tasks. After that you add a few records that every project needs.

> **In simple words:** Turn on what you need, add stages and tags, then create a project.

## Setup order

1. Open the [Project settings](project-settings.md). Switch on **Enable Project Stages**, **Enable Milestones** and **Enable Timesheets** as needed.
2. Open `Project → Configurations → Project Stages`. Add the phases of a project. Example: **To Do**, **In Progress**, **Done**, **Cancelled**. See [Project stages and milestones](../project-management/project-stages-and-milestones.md).
3. Open `Project → Configurations → Tags`. Add labels such as **Design** or **Client Work**. See [Tags](../configuration/tags.md).
4. [Create a project](../project-management/create-project.md).
5. Add task stages to that project, such as **New**, **In Progress**, **Review** and **Done**. See [Task stages and states](../task-management/task-stages-and-states.md).
6. [Create a task](../task-management/create-task.md).

::: warning Task stages come first
A new project has no task stages. A task cannot be saved until its project has at least one stage. Add the stages before you create tasks.
:::

## What each switch adds

| Switch | What it adds |
| --- | --- |
| **Enable Project Stages** | A stage bar at the top of the project form |
| **Enable Milestones** | **Allow Milestones** on projects, a **Milestone** field on tasks |
| **Enable Timesheets** | **Allow Timesheets**, hours fields, a **Timesheets** tab on tasks |
