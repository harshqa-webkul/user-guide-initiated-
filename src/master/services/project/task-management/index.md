# Task management

A task is one piece of work with a title, an owner, a deadline and a place in your workflow. Tasks usually belong to a project, and big tasks can be split into sub-tasks. This group shows you how to set up the workflow, create tasks, find them again and track the time spent.

> **In simple words:** Tasks are the to-do items of a project. Stages show where each one is, and the State shows how it is going.

Open `Project → Tasks` to see every task you are allowed to see.

## The flow

```text
Task stages  ──►  Task  ──►  State  ──►  Sub-tasks  ──►  Time
(per project)    (create)   (progress)   (split work)   (rolls up)
```

1. **Add task stages to the project.** A task cannot be saved until its project has at least one stage. See [Task stages and states](task-stages-and-states.md).
2. **Create the task.** Fill the title, assignees, deadline and allocated hours. See [Create a task](create-task.md).
3. **Keep the State up to date.** The State says whether work is in progress, approved or done.
4. **Split large work into sub-tasks.** See [Sub-tasks](sub-tasks.md).
5. **Log time.** Hours logged on sub-tasks add up on the parent task. See [Log time](../../timesheets/log-time.md).

## Running example

The guide follows the project **Website Revamp** for the customer **Azure Interiors**. Its task stages are **New**, **In Progress**, **Review** and **Done**. You will create the task **Prepare launch announcement** and a sub-task **Draft email copy** under it.
