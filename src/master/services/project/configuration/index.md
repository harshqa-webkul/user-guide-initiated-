# Configuration

Configuration holds the small lists that other Project pages draw from. You set them up once, then pick from them when you create projects and tasks. This group covers the two lists that serve both projects and tasks: tags and activity plans.

> **In simple words:** Configuration is the set of labels and checklists your team reuses on every project and task.

Open `Project → Configurations`. The menu also holds **Project Stages**, **Task Stages** and **Milestones**. Those belong to the project and task flow.

## What each list does

| List | Used for |
| --- | --- |
| [Tags](tags.md) | Coloured labels on projects and tasks for grouping and filtering |
| [Activity plans](activity-plans.md) | Ready-made sets of follow-up activities you start from Chatter |
| Project Stages | The steps of a project. See [Project stages and milestones](../project-management/project-stages-and-milestones.md) |
| Task Stages | The steps of tasks inside one project. See [Task stages and states](../task-management/task-stages-and-states.md) |

## How they connect

```text
Tag  ──►  shown on  Project and Task cards, used in filters
Activity plan  ──►  started from the Chatter of a Project or Task
```

## Suggested order

1. Create the tags your team needs, such as **Design** or **Client Work**.
2. Create activity plans for routines you repeat, such as a launch checklist.
3. Use the tags and plans when you [create a project](../project-management/create-project.md) or [create a task](../task-management/create-task.md).

::: tip
Archive a tag or plan with **Delete** when you stop using it. **Restore** brings it back. **Force delete** removes it for good.
:::
