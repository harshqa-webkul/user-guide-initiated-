# Tags

A tag is a short coloured label. You stick it on a project or a task so you can spot and filter related work quickly. One shared list serves both projects and tasks.

> **In simple words:** A tag is a coloured sticker. Create it once and use it on any project or task.

Open `Project → Configurations → Tags`.

## Overview

The list shows each tag with its **Name** and **Color**. Use the row menu for **Edit**, **Delete**, **Restore** and **Force delete**. Tick rows for the same bulk actions.

<ImagePopup src="/images1/project/cf_tags_list.png" alt="Tags list with each tag name and its colour" />

## Create a tag

The example creates the tag **Client Work**.

1. Open `Project → Configurations → Tags` and click **New Tag**.
2. Fill in the form.

   - **_Name:_** (required) A unique name, for example **Client Work**.
   - **_Color:_** The label colour. The default is grey. Pick a colour that stands out, such as orange.

   <ImagePopup src="/images1/project/cf_tag_form.png" alt="Tag modal with name Client Work and an orange colour" />

3. Click **Create**. The tag now appears in the list.

You can also create a tag while filling a project or task. Open the **Tags** field and use the create option. Give the **Name** and **Color**.

## Use a tag

- On a project, pick tags in **Additional Information**. They show as badges on the project card.
- On a task, pick tags in **General**. They show in the **Tags** column of the task list.
- Filter the project list, the task list or the dashboard by **Tags**.

In **Website Revamp**, the tags are **Requirements**, **Testing**, **Documentation**, **Client Work** and **Design**.

::: info
A tag name must be unique. Delete archives a tag, so it can no longer be picked until you restore it.
:::
