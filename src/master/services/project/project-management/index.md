# Project management

A project is the container for all the work of one job. It stores the customer, the manager, the dates and the rules for time and milestones. Tasks, milestones and hours all hang from it.

> **In simple words:** Create the project first, then organise its phases and watch it on the dashboard.

## The flow

1. Check the [Project settings](../get-started/project-settings.md) so the right fields appear.
2. Add global project stages and per project milestones. See [Project stages and milestones](project-stages-and-milestones.md).
3. [Create a project](create-project.md). Pick a customer, a manager and dates.
4. Add task stages and tasks. See [Task management](../task-management/index.md).
5. Read totals in the [Project dashboard](project-dashboard.md).

## Pages in this group

- [Create a project](create-project.md): the card list, the form, the view page, archive and restore.
- [Project stages and milestones](project-stages-and-milestones.md): the phases of a project and the key points inside it.

## Good to know

- **Project stage**, **task stage** and task **State** are three different things. See [Task stages and states](../task-management/task-stages-and-states.md).
- **Delete** archives a project. You can restore it from the **Archived Projects** tab.
- The customer comes from [Contacts](../../../getting-started/contacts/contacts.md).
