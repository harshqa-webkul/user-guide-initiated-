# Timesheets

A **timesheet** entry records the time someone spent on a task. Each entry names the date, the employee, the project, the task and the hours. Use timesheets to see where time goes and to compare the time spent on projects and tasks.

> **In simple words:** A timesheet is a diary of who worked on what, and for how long.

## Settings

Timesheets need to be turned on for projects.

1. Go to `Project → Settings → Manage Time`.
2. Turn on **Enable Timesheets**.
3. Save the changes.

See [Project settings](../project/settings.md) for the full list of project settings.

## Overview

Open `Timesheets` from the main menu to see all entries in a list. The list shows these columns: **Date**, **Employee**, **Project**, **Task**, **Description** and **Time Spent**. **Created At** and **Updated At** are also available from the column manager.

<!-- TODO-SCREENSHOT: /images1/services/timesheets_list.png | Timesheets list with the columns and toolbar -->

Use the toolbar to find entries. See [Search, filter and group records](../../getting-started/search-filter-group.md).

- **Group by:** **Date**, **Employee**, **Project**, **Task** or **Creator**.
- **Filters:** **Date From**, **Date Until**, **Employee**, **Project**, **Task** and **Creator**.

## Add a timesheet entry

1. Go to `Timesheets` and click the button to add a new entry.
2. Fill in the form:

   - **_Date:_** The day the work was done. This field is required.
   - **_Employee:_** The person who did the work. This field is required.
   - **_Project:_** The project the work belongs to. This field is required.
   - **_Task:_** The task the work belongs to. This field is required.
   - **_Description:_** A short note on what was done.
   - **_Time Spent:_** The time in hours. This field is required. For example, `1.5` means 1 hour 30 minutes.

   <!-- TODO-SCREENSHOT: /images1/services/timesheet_form.png | Timesheet form filled in -->

3. Save the entry.

::: tip
You can also add time from a task. Open the task and use its **Timesheets** tab. See [Tasks](../project/tasks.md).
:::

## Edit or delete an entry

On the list, use the actions at the end of a row to edit or delete an entry. To delete several entries at once, tick them and use the bulk delete action.
